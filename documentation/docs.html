NAME

infinity — a social network for programmers _Built for devs by devs

SYNOPSIS

infinity [feeds|snippets|bookmarks|jobs] [--pro]

DESCRIPTION

Infinity combines a discussion feed with a code snippet library for developers. It’s designed to reduce context switching so you can learn from conversations and reuse code without leaving the app. This document explains each feature and how to use it.

GETTING STARTED

  1. 1. Create an account from the login page, or sign in if you already have one.
  2. 2. Fill out your profile — a bio and avatar help people recognize you easily.
  3. 3. Post something. A question, a code snippet, a video or even resources— whatever can help.
  4. 4. Follow a few people from the feed to shape what shows up next time.

Don't paste API keys, tokens, or credentials into a snippet — once posted, it's public. See Privacy Policy for details.

BOOKMARKS(1)

Anything you save from Feeds, Snippets, or Jobs collects here in one list, most recent first. Saving doesn't notify the original author.

JOBS(1)

A listings board scoped to dev roles. Post an opening from the same Create Post flow used for regular posts — Jobs is a category, not a separate form.

PRO(1)

An optional upgrade. Details on what it currently unlocks live on the Pro page linked from the sidebar — this doc will get a real flag list once that feature set is finalized.

ACCOUNT(1)

Profile details, password, and notification preferences live under Settings. Data handling and deletion requests are covered in the Privacy Policy, not here.
