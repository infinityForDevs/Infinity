Debounce hook that actually cancels on unmount

Ran into stale closures with the usual debounce hook pattern. This version clears the timeout on unmount and re-creates it only when the delay changes.

useDebounce.js 
function useDebounce(value, delay) {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debounced;
}

One-liner to flatten a nested list of any depth

No imports needed. Recursive generator, works on arbitrarily nested lists/tuples.

flatten.py 
def flatten(nested):
    for item in nested:
        if isinstance(item, (list, tuple)):
            yield from flatten(item)
        else:
            yield item
